# CampusBank - Online Banking System

A mini online banking system built using **HTML, CSS, and JavaScript** for a college project.

## Features

- Student login (demo authentication)
- Account balance and account summary
- Quick transfer to recipient
- Bill payment module (electricity/mobile/internet/water)
- Transaction history log
- Toast notifications for actions
- Responsive design

## Run Locally

You can open `index.html` directly, or use a local server:

```bash
python3 -m http.server 8000
```

Then visit: `http://localhost:8000`

## Project Structure

- `index.html` - app layout and forms
- `styles.css` - UI styling and responsive layout
- `app.js` - app logic, validation, and transaction handling
